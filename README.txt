HOW TO USE ON ANY WINDOWS PC:

1. Extract this zip file anywhere (or keep on your USB Flash Drive).
2. FIRST-TIME SETUP (on a new computer):
   - Make sure Python 3.10+ is installed (from python.org with "Add Python to PATH").
   - Double-click "INSTALL_DEPENDENCIES.bat" to install required packages.
   - Make sure Ollama is installed (ollama.com) and has your favorite model 
     (e.g., run `ollama run qwen2.5-coder:7b` or `ollama run qwen2.5-coder:1.5b`).

3. TO RUN CIEL:
   - Simply double-click "RUN_CIEL.bat" or "Ciel.exe".
   - The desktop HUD window will open maximized with hands-free voice ready!
